# ROADMAP

> 顺序由**依赖关系**决定，不由规格 Phase 编号决定。
> 规格有 84 个 Phase；这里只列能推动"可运行产品"往前走的里程碑。

## M0 可运行原型 ✅ 已完成
城市生成 / 流式 / 昼夜天气 / 人群车流 / 地标 / 第三人称与驾驶。
证据：`Pipeline/run.sh` 全绿，289/289 chunk，稳态 45–55 FPS。

## M1 创造闭环 ✅ 大部分完成
放置·变换·复制·删除·撤销·存盘·读盘 + 建筑 12 模板 + 道路 + 合法性校验。
**未完成**：地形/装饰/车辆/NPC/任务工具、3D 拖拽 Gizmo。

## M2 性能达标 ← 当前所在
目标：单 chunk 构建 ≤ 7 ms（现 17.7 ms）。
路径：`CityData` 共享缓存线程安全化 → `WorkerThreadPool` 并行构建 → 沿江距离场粗-精两级化。
阻塞点：当前 GDScript 静态函数读写 autoload 共享缓存，非线程安全。

## M3 服务器权威后端（部分完成）
已做：账号双令牌与轮换、三代存档与损坏自愈、append-only 账本、UGC 上传即校验。
待做：把这些接到客户端（现在客户端仍只写 `user://`），加 HTTPS 与部署。

## M4 多人最小闭环
玩家位置/车辆/已建作品的 replicated 状态 + 服务器权威移动校验。
这是 M5-M8 的前置，**不能跳过**。

## M5 大地图与主菜单（游戏外壳）
可缩放旋转的城区地图、搜索、主菜单、设置界面。

## M6 AI 创造流程补全
Intent Parser → Planner → Generate → Validate → Cost Estimate → **Preview → Confirm** → Execute → Persist。
前置：M3 的 AI 网关契约（密钥不进客户端、限流、缓存、成本记录）。

## M7 UGC 平台前端
浏览/搜索/订阅/收藏/举报 + 包下载与本地装配（**只允许数据，禁止可执行**）。

## M8 运营与发行
监控告警、崩溃报告、分析看板、存档版本迁移、Steam 打包与 QA/RC/Production 通道。

## 明确不做（直到有玩家）
动态实例自动扩缩、创作者收益结算（需支付通道与经营主体）、
云存档多区域同步、K8s 编排、微服务拆分。
理由：零玩家时这些不增加任何保证，只增加无法验证的表面积。
